Inspect the CronJobs:
  kubectl -n {{ .Release.Namespace }} get cronjobs -l app.kubernetes.io/instance={{ .Release.Name }}

Tail the next firing of a specific CronJob:
  kubectl -n {{ .Release.Namespace }} get jobs -l app.kubernetes.io/component=hourly --sort-by=.metadata.creationTimestamp | tail
  kubectl -n {{ .Release.Namespace }} logs -f -l app.kubernetes.io/component=hourly --tail=200

Manually trigger a one-off run from a CronJob (debug only):
  kubectl -n {{ .Release.Namespace }} create job manual-$(date +%s) \
    --from=cronjob/{{ include "bcp-ingestion-pipeline.fullname" . }}-hourly

Confirm the External Secret synced:
  kubectl -n {{ .Release.Namespace }} get externalsecret {{ include "bcp-ingestion-pipeline.fullname" . }}
  kubectl -n {{ .Release.Namespace }} get secret {{ include "bcp-ingestion-pipeline.secretName" . }}
